# Контактні форми у попап-банерах

## Призначення

Тип кампанії `lead_form` збирає контактні дані покупця й відкриває промокод лише після успішного збереження форми. Хорошоп залишається джерелом істини для самого промокоду, а KramKit зберігає окремий список контактів для кожної кампанії.

## Конструктор форми

Кампанія підтримує до 12 полів. Для кожного поля налаштовуються назва, тип, підказка, обов'язковість і порядок. Доступні типи:

- однорядковий текст;
- email;
- телефон;
- багаторядковий текст;
- список із власними варіантами;
- чекбокс згоди.

Окремо задаються текст кнопки відправлення, заголовок і пояснення успішного результату. Для кампанії обов'язково вибирається промокод із бібліотеки. Під час публікації створюються незмінні snapshot-и форми й промокоду; подальше редагування чернетки або бібліотеки не змінює активну версію без повторної публікації.

## Публічна поведінка й захист коду

Публічний `resolve` повертає структуру опублікованої форми, але не повертає промокод. Вітринний runtime відправляє значення на `POST /api/public/popup-banners/:publicId/contacts`. Сервер повторно перевіряє активність кампанії, розклад, магазин, усі поля й лише після запису контакту повертає snapshot промокоду.

Повторна відправка однакового набору значень у межах кампанії не створює ще один контакт, але знову повертає промокод користувачеві. Endpoint має окреме обмеження частоти запитів. Поля email, телефону, списку та обов'язкової згоди перевіряються сервером, тому клієнтську валідацію не можна вважати межею безпеки.

Оскільки форма рендериться всередині власного runtime KramKit, вона не залежить від селекторів Хорошопа. Поведінка окремо перевіряється з desktop та mobile User-Agent і viewport.

## Списки контактів

У збереженої кампанії є вкладка **«Зібрані контакти»**. Таблиця будує колонки відповідно до полів конкретної форми й показує дату та сторінку надсилання. Контакти однієї кампанії не змішуються з контактами іншої.

Адміністративні endpoint-и:

- `GET /api/popup-banners/:id/contacts` — сторінка контактів кампанії;
- `GET /api/popup-banners/:id/contacts/export` — XLSX цієї кампанії;
- `GET /api/popup-banners/contacts/export` — один XLSX з окремим аркушем для кожної контактної кампанії.

Експорт екранує значення, які Excel може інтерпретувати як формули. Назви аркушів очищуються від несумісних символів та обмежуються довжиною Excel.

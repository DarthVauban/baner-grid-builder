# Блоковий конструктор попап-банерів

Редактор відкривається через **Попап-банери → Блоковий конструктор** або за маршрутом /tools/popup-banners/builder. Доступ захищено тією самою авторизацією та дозволом popup_banners, що й наявні прототипи.

## Поточні можливості

- Дерево горизонтальних і вертикальних flex-контейнерів: до 120 блоків включно з коренем і 12 рівнів вкладеності після кореня.
- Текст, зображення за URL, кнопка, роздільник, відступ, промокод, таймер, форма, поле форми й контейнер товару. Товар складається зі звичайних вкладених елементів, які можна змінювати окремо.
- Перенесення між контейнерами перетягуванням на полотні чи в шарах. Лінія між шарами задає позицію перед/після; середина контейнера додає в кінець. Також є вибір батьківського контейнера, зміна порядку, підняття на рівень, обгортання, дублювання й видалення гілки.
- Розміри у px, %, за вмістом або із заповненням; мінімальна висота, максимальна ширина, grow/shrink, перенесення рядків, вирівнювання по двох осях, проміжки, чотири сторони padding/margin, рамка, фон, тінь, типографіка, прозорість і видимість.
- Desktop є основою стилів. Mobile зберігає лише явні перевизначення; можна скинути їх для вибраного елемента. Нові горизонтальні контейнери мають мобільний напрямок «колонка».
- Зум 10–300%, вписування, обмежене переміщення, колесо, Ctrl/⌘ + колесо, пробіл + перетягування, середня кнопка, інструмент переміщення, pinch на сенсорних пристроях.
- Повноекранний перегляд зі збереженням перемикача Desktop/Mobile і кнопки виходу; Escape повертає редактор.
- До 50 кроків undo/redo, локальне автозбереження окремо для користувача, імпорт та експорт JSON. Ctrl/⌘ + Z — скасувати, Ctrl/⌘ + Shift + Z — повторити, Ctrl/⌘ + D — дублювати, Delete — видалити вибраний вкладений блок. У полях введення зберігаються стандартні клавіші редагування тексту.

## Межа інтеграції

Це функціональне продовження прототипів, а не новий тип опублікованої кампанії. Макет зберігається в localStorage під ключем mt-popup-block-builder-v1:<userId>. Редактор не надсилає запитів створення/оновлення кампаній і не змінює storefront loader. Зв’язування із каталогом, переходи та кошик демонструються на демотоварах. Форма перевіряє обов’язкові поля і показує результат локально; введені контакти не зберігаються й не надсилаються. Копіювання промокоду та приховування банера працюють у тестовому перегляді.

Для публікації потрібен окремий узгоджений контракт дерева кампанії: серверна валідація, версія опублікованого макета, серіалізація, клієнт API та типи, storefront renderer, прив’язування реальних товарів/промокодів і обробка контактів. Це має супроводжуватися серверними тестами та незалежними storefront E2E для desktop і mobile. Поточні кампанії та їхній embed-код не змінені.

## Структура коду

- client/src/components/popup-builder/block-model.ts — схема документа, перевірки структури, чисті операції над деревом.
- templates.ts — початкові композиції, побудовані з тих самих блоків.
- useBlockDocument.ts — історія та локальне збереження.
- BlockTree.tsx, BlockInspector.tsx, BlockRenderer.tsx — дерево, властивості, рекурсивне полотно та тестові взаємодії.
- client/src/pages/PopupBlockBuilderPage.tsx — координація редактора та навігація.
- Полотно використовує наявний usePrototypeViewport.

Імпорт обмежено 500 КБ. До рекурсивного розбору перевіряються кількість, глибина, унікальність ID та семантика форм. Заборонені циклічні перенесення, вкладені форми, поля за межами форми та діти у листових елементів. Дублювання створює нові ID для всієї гілки. Помилка імпорту чи перенесення залишає попередній документ. Пошкоджений локальний запис не перезаписується до першої зміни. JSON не виконується як HTML чи JavaScript; стилі обмежені схемою.

## Перевірки

npm run verify

npx playwright test tests/e2e/popup-block-builder.spec.ts tests/e2e/popup-prototypes.spec.ts --output=tmp/popup-block-e2e

Модель перевіряє вкладеність, переміщення, дублювання, обгортання, обмеження імпорту та мобільне успадкування. E2E перевіряє редагування з чистого аркуша, drag-and-drop, збереження/undo/redo, перенесення JSON, форму, таймер, fullscreen та mobile з мобільними User-Agent і viewport.

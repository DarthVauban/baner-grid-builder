# Десктопний парсер фото Хорошоп

## Призначення

Вебінструмент формує точну вибірку товарів або модифікацій з імпортованого каталогу Хорошоп. Десктопний застосунок виконує керований пошук сторінок-джерел, збирає фото своїми адаптерами та повертає вибрані зображення у відповідні чернетки робочого простору. Публікація чернеток у Хорошоп лишається окремою явною дією адміністратора.

## Робочий процес

1. Адміністратор створює одноразовий код підключення у вебінструменті.
2. Десктопний парсер обмінює код на окремий токен пристрою.
3. Адміністратор створює вибірку за назвами/артикулами або фільтрами та передає її у парсер.
4. Для кожної активної модифікації створюється окреме завдання; товар без модифікацій отримує завдання спільної галереї.
5. Парсер фіксує HTTPS-сторінку-джерело, показує знайдені фото та передає лише вибрані.
6. Сервер складає фото у тимчасову staging-чергу та атомарно замінює склад локальної чернетки після команди завершення.
7. Адміністратор переглядає чернетку у вебінструменті й окремо публікує її в Хорошоп.

## Безпека

- Код складається з 12 символів, діє 10 хвилин, зберігається лише як HMAC і може бути використаний один раз.
- Endpoint обміну коду обмежений за частотою запитів.
- Токен пристрою має 256 біт ентропії та зберігається в БД тільки як HMAC.
- Кожен запит повторно перевіряє стан користувача, доступ до інструмента та вимогу 2FA.
- Пристрій бачить тільки завдання, створені тим самим користувачем.
- Оренда завдання не дозволяє двом пристроям одночасно завершувати одну позицію; прострочені оренди повертаються у чергу.
- Джерела фотографій мають використовувати HTTPS. Завантаження обмежене 8 МБ на файл і 40 фото на товар.
- Токен у десктопному застосунку доступний лише Electron main process і зберігається зашифрованим через Windows DPAPI (`safeStorage`).

## API

Адмінські endpoint-и під `/api/search/horoshop/photos/desktop` створюють код, показують пристрої та відкликають доступ. Device API під `/api/desktop/photo-parser` використовує Bearer-токен і надає операції черги: list, claim, heartbeat, source, asset upload, complete, fail та release.

## Відновлення й очищення

- Якщо застосунок закрився, оренда спливає через 10 хвилин, після чого інший або той самий пристрій може забрати завдання знову.
- Відкликання пристрою одразу повертає його активні завдання у чергу.
- Невдале завершення видаляє staging-файли й фіксує причину в чернетці.
- Відключення інтеграції Хорошоп видаляє вибірки, чернетки, завдання, staging-записи та пов'язані медіафайли разом з рештою імпортованого каталогу.
